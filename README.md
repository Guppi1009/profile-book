# プロフィール帳（人物・キャラクター検索）

名前を入れると、左に画像、右に「名前・出身・年齢・好きなもの・嫌いなもの・できること・できないこと」の7項目を1画面で表示するミニアプリ（できる／できないは英語の can / can't の練習用）。
**完全無料・APIキー不要・サーバー不要**。`プロフィール帳.html` をブラウザで開くだけで動く。

## 使い方
1. `プロフィール帳.html` をダブルクリック（Chrome / Edge / Safari）
2. 名前を入れて「しらべる」（Enterでも可）
3. 別の人が出たときは、検索欄の下に並ぶ候補チップを押すと切り替わる
4. `プロフィール帳.html?q=大谷翔平` のようにURLに名前を付けると、開いた瞬間に検索する

## みんなで使うとき
- ファイルをそのまま配布（Teams・Classroom・USB）すればOK。各自の端末で開くだけ
- 通信先は Wikipedia / Wikidata だけ。学校のフィルタで ja.wikipedia.org・en.wikipedia.org・www.wikidata.org・upload.wikimedia.org が開ければ動く
- 1回の検索で3〜5回の通信。回線が普通なら1〜3秒で表示

## 情報の出どころ（AIは使っていない）
| 項目 | 取り方 |
|---|---|
| 画像 | 日本語版Wikipediaの代表画像 → 英語版Wikipedia（アニメ・ゲームのキャラ画像はこちらに多い）→ Wikidata の順で探す |
| 名前 | 記事名＋ふりがな（記事冒頭の（かっこ））＋Wikidataの説明文 |
| 出身 | Wikidata の出生地／国籍。キャラクターは本文の「〜出身」、なければ登場作品名 |
| 年齢 | Wikidata の生没年から計算（故人は「◯歳で死去」）。キャラクターは本文の「年齢は◯歳」「誕生日は◯月◯日」 |
| 好きなもの・嫌いなもの | Wikipedia本文の「好物は〜」「〜が好き」「趣味は〜」「愛用」「〜のファン」「〜が嫌い」「〜が怖い」「アレルギー」などの文から抜き出す |
| できること・できないこと | 本文の「特技は〜」「〜が得意」「〜ができる」「〜に長け」／「〜が苦手」「〜ができない」「〜が下手」などから抜き出す。無ければ Wikidata の職業（野球選手→野球）を「できること」に使う |
| 日本語に無いとき | 英語版Wikipediaの本文からも探す（英語のまま表示・「英語版Wikipediaより」と注記） |
| それでも無いとき | 「ー」と出て、横に「🔍 Googleで調べる」ボタン。タップで検索結果が開く（AIは使わない・2026-09-18ユーザー判断） |

- 記事に書かれていない項目は「ー」と出る（作り話はしない）
- 「記事を見る ↗」で元のWikipedia記事が開くので、そこで確かめられる

## 画像が出ないとき（タブレット対応・2026-09-18改訂）
まず自動で Wikipedia（日本語→英語）→ Wikidata → Wikimedia Commons（ファイル名に名前を含む写真だけ）の順に探す。
それでも無いときは、左枠に3つのボタンが出る。マウス不要・タップだけでOK。
1. 「🔍 Google画像で探す」→ 別タブで画像を長押し →「コピー」（iPad）／「画像をコピー」（Android）
2. 戻って「📋 コピーした画像を貼る」をタップ（初回は貼り付けの許可を聞かれる）
3. うまくいかないときは「📷 写真からえらぶ」で、保存した写真やスクリーンショットを選ぶ
出てきた画像が違うときは、画像下の「🔄 かえる」で同じボタンが出る。
貼った画像はその端末に記憶され、次に同じ名前を調べたときも出る（大きな写真は1000pxに縮小して保存）。

## 任意：Google画像の1枚目を使いたいとき
ファイル冒頭の `GOOGLE_API_KEY` と `GOOGLE_CSE_ID` にキーを入れると、画像だけ Google 画像検索の1枚目（セーフサーチON）に切り替わる。
無料枠は 1日100回まで。課金を有効にしなければ 101回目以降はエラーになるだけで請求は発生しない（Wikipedia画像に自動で戻る）。
1. https://programmablesearchengine.google.com/ で検索エンジンを作成（「ウェブ全体を検索」ON・「画像検索」ON）→ 検索エンジンID を控える
2. https://console.cloud.google.com/ で「Custom Search API」を有効化 → APIキーを作成
3. HTML冒頭の2つの定数に貼る

※ キーはHTMLの中に平文で入るので、生徒に配るファイルには入れない方が安全。
